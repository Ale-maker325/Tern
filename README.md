# Екосистема апаратури Tern та прошивки MLT-2

**Tern** — це екосистема компактних кастомних плат та автономних тактичних LoRa-комунікаторів, розроблена для роботи в умовах відсутності базової інфраструктури, високого рівня перешкод та складних польових умов.

Проєкт об'єднує в собі апаратну платформу **Tern** (на базі мікроконтролерів nRF52840 / ESP32-S3 та радіомодемів Ebyte E22/SX126x) та спеціалізовану прошивку **MLT-2** (Mesh Tactical Protocol v2).

---

## 📌 Ключові особливості MLT-2

- **Дворівнева модель довіри:** Суворе розмежування загальної бази пристроїв (Directory) та оперативного списку зв'язку («Книга» / Active Roster).
- **Радіомаскування:** Одноканальна broadcast-передача зашифрованих пакетів без відкритих підтверджень (ACK), які демаскують групу в ефірі.
- **Наскрізне шифрування:** Криптозахист корисного навантаження (payload) на базі AES-128-CBC з динамічним детермінованим IV (без передачі IV в ефір).
- **Автономний UI:** Повне налаштування та управління мережею через OLED-дисплей однією кнопкою, BLE-UART або текстовий CLI-термінал.
